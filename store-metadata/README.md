# store-metadata — материалы для публикации КОРⱯ

Собрано для релиза 1.0.1 в App Store и Google Play. Все тексты сверены с кодом приложения —
указано только то, что приложение реально умеет.

## Структура
- `common.md` — идентификаторы, ссылки, категории, конфиденциальность, разрешения.
- `app-store/ru.md`, `app-store/en.md` — листинг App Store (имя, подзаголовок, описание, ключевые слова).
- `app-store/surveys-and-review.md` — ответы на опросы ASC (privacy, age rating, шифрование) + заметки ревью.
- `google-play/ru.md`, `google-play/en.md` — листинг Google Play.
- `google-play/data-safety-and-rating.md` — Data safety и Content rating.
- `screenshots/<lang>/<device>/` — скриншоты (РЕАЛЬНЫЙ UI приложения с демо-данными):
  - `iphone65` — 1284×2778 (iPhone 6.5″)
  - `ipad13` — 2048×2732 (iPad 13″ / 12.9″)
  - кадры: `01-tree`, `02-detail`, `03-edit`, `04-trees`, `05-settings`

## ⚠️ Проверить/исправить ДО отправки сборки
1. **Android: `RECORD_AUDIO`** в `app.json` (`android.permissions`) — НЕ используется в коде
   (микрофона/записи звука нет). Удалить, иначе вопросы на Data safety в Play.
2. **Камера** — объявлены `NSCameraUsageDescription` (iOS) и подразумевается камера в
   Privacy Policy, но в коде только выбор из галереи (`launchImageLibraryAsync`),
   вызова камеры нет. Варианты: либо убрать упоминание камеры (и `NSCameraUsageDescription`),
   либо реально добавить съёмку. Сейчас тексты сторов написаны БЕЗ упоминания камеры — честно.
3. **Privacy Policy** упоминает доступ к камере — привести в соответствие (см. п.2).

## Замечание по скриншотам (web-сборка)
Скриншоты сняты с web-версии (по согласованию). Экраны «дерево / карточка / редактирование /
список деревьев» визуально идентичны нативной версии. Отличия web-сборки, которых НЕ будет в
нативном приложении: кнопки масштабирования «−/+» в углу дерева (на телефоне — жест «щипок»)
и блок «Скачать мобильное приложение» в Настройках. Если важна максимальная точность —
эти кадры можно переснять на iOS-симуляторе.
